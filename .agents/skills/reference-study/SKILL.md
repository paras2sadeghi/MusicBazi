# reference-study

Turn a reference track into a written entry I can confirm. Builds
`music/reference-artists.md` one track at a time.

Follows `AGENTS.md`; never overrides its safety rules.

## Inputs

- Artist + track (required). Which lane it's for (ask if unclear).
- Optional: a clip in Live where I've sketched or imported part of it.

## Steps

1. **Separate fact from guess.** Agents can't listen to audio. Use:
   - what I tell you about it;
   - Live data if I've placed MIDI or audio in a set (read tempo, warp markers,
     clip notes — read-only);
   - general knowledge of the track, clearly labelled *(unverified)*.
2. **Ask me what I hear.** 3–5 short questions: what grabs you, which part,
   which sound, what feeling.
3. **Draft the entry** in the format in `music/reference-artists.md`. Mark every
   unverified field.
4. **Propose borrowable principles** for `music/taste-log.md` (status `open`).
5. **Write only what I confirm.**

## Don't

- Don't reproduce lyrics or transcribe a copyrighted melody note-for-note into
  Live. Borrow techniques and feel, not the tune.
- Don't search the web or disk unless I ask.

# brain

Turn a session into durable learning. **Propose only** — I approve each item.

Follows `AGENTS.md`; never overrides its safety rules.

## Gather

1. This conversation: what I kept, rejected, asked for, complained about.
2. Live state now (read-only): tracks, clips, names — what survived.
3. The track journal and `music/taste-log.md` (to avoid duplicates and to spot
   contradictions with existing rules).

## Propose

Present a numbered list, grouped:

- **Taste-log** — new principles or status changes (`open` → `kept`, etc.),
  each with category, one-line rule, why, and source.
- **Contradictions** — where today's choices disagree with an existing rule. Ask
  which wins; never silently overwrite.
- **Journal** — session log entry (did / kept / rejected / next) and any decisions.
- **Other taste files** — e.g. a tempo for a lane in `genres.md`, a go-to preset
  in `palette.md`, an upgrade want in `production.md`.
- **AGENTS.md / skills** — only if a workflow problem came up. Flag it; don't edit.

## Apply

Write only the items I approve (e.g. "1, 3, 4"). Report what changed. Offer to
commit; don't push.

## Don't

- Don't infer a principle from a single offhand comment — mark it `open` at most.
- Don't edit `AGENTS.md` or skills from here.

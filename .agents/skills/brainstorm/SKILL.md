# brainstorm

Open-ended conversation about an idea. **No Live writes** until I say go.

Follows `AGENTS.md`; never overrides its safety rules.

## Flow

1. **Listen first.** Restate the idea in one line. Ask what it should *feel* like.
2. **Ground it in my taste.** Read `music/identity.md`, `music/genres.md` and
   `music/taste-log.md`. Point out where the idea matches or pushes against what's
   there — and where my files are silent.
3. **Widen.** Offer 3–5 directions (lane, tempo, mode, palette, structure),
   each in a sentence, each within Lite limits and my palette.
4. **Narrow.** Help me pick; ask one question at a time.
5. **Shape a brief** when it converges:

   ```markdown
   - Lane / tempo / mode:
   - Feel:
   - Core elements (≤ 4):
   - Palette:
   - First thing to build:
   ```

6. **Ask to move into Live.** On yes: create a journal from `tracks/_template.md`
   (propose the path), then either build it (generator role) or hand off to
   `ideate` / `arrange`.

## Reading Live during brainstorm

Reading session state is fine if it helps (e.g. "what's in this set?"). Writing
is not.

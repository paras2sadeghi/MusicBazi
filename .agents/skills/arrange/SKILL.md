# arrange

Move from loops to a song. My default is Session loops → Arrangement
(`music/production.md`).

Follows `AGENTS.md`; never overrides its safety rules.

## Before starting

1. Confirm the duplicated `.als`.
2. Read the lane's **Structure** in `music/genres.md`. If it's still
   `<!-- fill -->`, propose one for this track and ask before using it.
3. Read Live: tracks by name, Session clips and scenes, current Arrangement
   content. **If the Arrangement already has material, ask before writing over it.**

## Steps

1. **Map the material.** List each loop by track/scene with a role
   (intro, groove, hook, breakdown…).
2. **Propose a section plan** as a table:

   | Section | Bars | Start beat | Elements in | Elements out | Energy 1–5 |
   |---|---|---|---|---|---|

   Lengths in bars; convert to beats for tools (4 beats per bar in 4/4 — check
   the actual time signature). Stay within 16 tracks.
3. **On my yes**, copy clips to the Arrangement section by section. One undo
   batch per section; tell me the undo count.
4. **Transitions**: suggest fills, drops, risers using existing tracks or Lite
   stock devices. Ask before adding tracks.
5. Add locators per section if the server supports it.
6. Propose a journal update with the section plan.

## Don't

- Don't render, freeze or export.
- Don't change tempo or time signature without asking.

# ideate

Write several variants of one part as **experiments**, let me react, and turn my
reaction into a taste principle — only after I confirm.

Follows `AGENTS.md`; never overrides its safety rules.

## Before starting

1. Confirm the duplicated `.als` (AGENTS.md safety 1).
2. Read: `music/identity.md`, `music/theory.md`, the lane in `music/genres.md`,
   the matching category in `music/taste-log.md`, the track journal.
3. Read Live state: tracks by name, the clip(s) involved, actual pitch classes.

## Round

1. **Name the axis.** One variable per round, e.g. rhythm density, register,
   contour, note length, mode, swing, velocity shape. Suggest an axis from
   `open` taste-log items if I don't give one.
2. **Plan 3–4 variants** that differ *only* on that axis. Say what each tests.
3. **Write each variant to its own clip** (new clip slots, same track or a
   duplicate track — never overwrite the original). Name clips `V1 <axis>`, `V2 …`.
   One undo batch per variant.
4. Tell me which slots to audition.
5. **Collect my reaction**: keep / reject / "more like this", and why.

## After the round

- Propose 1–2 principles for `music/taste-log.md`, in the entry format, with
  status `kept` / `rejected` / `open` and source. **Wait for my yes** before writing.
- Note the round in the track journal's session log (propose, then write).
- Offer the next round: same axis refined, or the next axis.

## Don't

- Don't change more than one axis per round.
- Don't delete rejected variants without asking.
- Don't state a principle as mine before I confirm it.

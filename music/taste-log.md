# Taste log

Living principles, grouped by **type of movement**. This is where my taste
actually gets learned.

## Rules

- Agents **never invent** principles here. They come from me, or from ideate
  rounds / brain retrospectives that I confirm.
- Each principle has a status:
  - `kept` — do this
  - `rejected` — don't do this
  - `open` — candidate, still testing
- Each category has a status: `open` (actively exploring) · `done for now` · `skipped`.
- Record the source (session, track, date) so a rule can be traced back.

## Entry format

```markdown
- [kept] Principle in one line. — source: tracks/<lane>/<song>.md, 2026-11-01
  - Why: what I heard / reacted to
```
